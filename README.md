# 座敷童子（ホラーゲーム）

修学旅行で泊まった旅館が舞台の、一人称 3D ホラーゲーム。
目をさますと同じ部屋の友達がいない。広い旅館を歩きまわって、一番奥の「奥の間」を探す。

- 旅館はおよそ 74m × 74m。廊下が網の目のようにつながり、間取りは毎回ランダムに生成される
- 部屋は約 40 種類（客室・大広間・大浴場・厨房・ロビー・カラオケ・書庫・お手洗い・蔵・祭壇・鏡の間・庭 など）で、同じ部屋は 1 回しか出てこない
- スタートは「二年三組」の大部屋、ゴールは玄関から一番遠い小部屋（奥の間）

## 遊び方

```bash
npx http-server . -p 8123 -c-1
```

ブラウザで http://localhost:8123 を開く。`?seed=数字` を付けると同じ旅館を再現できる。

| キー | 操作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| マウス | 視点 |
| Shift | 走る |
| E | 戸を開ける・閉める・調べる（戸口を見れば、どちら側からでも） |
| F | 懐中電灯 |
| M | 地図（行ったところだけ表示） |
| Esc | 一時停止（マウス感度・視野角・明るさ・上下反転の設定） |
| Shift + R | 別の旅館で最初から |

## 構成

- `src/layout.js` 間取りの生成（廊下の網・区画の分け方・玄関からの距離）
- `src/building.js` 間取りから廊下・交差点・壁・部屋を組み立てる。部屋の種類の割りあて（重複なし）
- `src/rooms.js` 部屋の種類（小 6m・中 12×6m・大 12m 四方・庭）
- `src/bath.js` 大浴場（脱衣所・富士山の壁画・ひのきの湯船・洗い場・湯気）
- `src/architecture.js` 障子・ふすま・格子戸・ガラス戸・のれん、柱／長押／欄間つきの壁、竿縁天井
- `src/props.js` `src/props2.js` 家具・小物
- `src/textures.js` 素材（`assets/textures/` の画像は Higgsfield で生成）
- `src/main.js` 操作・設定・地図・灯り
- `assets/models/zashiki_warashi.glb` 座敷童子の 3D モデル（Higgsfield / Meshy で生成）
