# 座敷童子（ホラーゲーム）

修学旅行で泊まった旅館が舞台の、一人称 3D ホラーゲーム。
夜、部屋を出ると廊下がどこまでも続いている。角を曲がっても同じ廊下に戻ってくるが、
周回するたびに少しずつ様子がおかしくなり、6〜8 周目で角が「奥の間」へのふすまに変わる。
廊下ぞいの部屋は周回ごとにランダムに入れかわる（大浴場だけはいつも同じ場所）。

## 遊び方

```bash
npx http-server . -p 8123 -c-1
```

ブラウザで http://localhost:8123 を開く。`?seed=数字` を付けると同じ旅館を再現できる。

| キー | 操作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| マウス | 視点 |
| Shift | 走る |
| E | 戸を開ける・調べる |
| F | 懐中電灯 |
| R | 別の旅館を生成 |

## 構成

- `src/corridor.js` ループする廊下の 1 区間（まっすぐ 28.8m ＋ 右に曲がる角）と、周回ごとの異変
- `src/main.js` 区間のつなぎかえ（角を曲がったら座標ごと次の区間へ移す）・プレイヤー操作・灯り
- `src/architecture.js` 障子・ふすま・格子戸・ガラス戸・のれん、柱／長押／欄間つきの壁、竿縁天井
- `src/bath.js` 大浴場（脱衣所・富士山の壁画・ひのきの湯船・洗い場・湯気）
- `src/rooms.js` 廊下ぞいの部屋（16 種）
- `src/props.js` 家具・小物
- `src/textures.js` 素材（`assets/textures/` の画像は Higgsfield で生成）
- `assets/models/zashiki_warashi.glb` 座敷童子の 3D モデル（Higgsfield / Meshy で生成）
