# 座敷童子（ホラーゲーム）

小学校の修学旅行で泊まった、3 階建ての古い旅館が舞台の一人称 3D ホラーゲーム。
目をさますと六年二組の部屋にはだれもいない。旅館を歩きまわって、3 階のいちばん奥にある「奥の間」を探す。

- 間取りは固定（`src/plan.js`）。実際の旅館を参考に、部屋ごとに大きさがちがう（客室は 10 畳＋広縁、大広間は 100 畳級、茶室は 4.5 畳など）
- 1 階：玄関 → ロビー → 帳場（奥に女将の部屋）・売店・喫茶。中庭を回廊が囲む。西に大浴場・露天風呂・湯上り処・遊技場、東に厨房・大広間・カラオケ、裏に洗濯室・ボイラー室・控室・食品庫、庭（竹林・井戸・墓地）
- 2 階（客室の階・廊下は赤いじゅうたん）：中庭を見下ろす回廊のまわりに客室（六年二組の大部屋・先生の部屋・桔梗の間・鶴の間・松の間・萩の間）、共同のお手洗い・洗面所、貸切風呂・麻雀部屋・救護室・書庫・茶室・布団部屋
- 客室は実際の旅館と同じ作り：入口の踏込と上がり框 → 前室（トイレ・洗面） → 障子の仕切り → 本間（座卓・座椅子・床の間と違い棚・押入れ・テレビ・冷蔵庫と金庫・衣桁の浴衣・乱れ箱） → 窓ぎわの広縁
- 3 階（古い別棟）：仏間・人形の間・鏡の間・祭壇の間・封じられた部屋・子ども部屋・物置・蔵・屋上の石庭・奥の間
- 部屋は 44 種類で、同じ部屋は 1 つだけ。廊下の障子窓も開けられる

## 座敷童子とのかくれんぼ

- はじめて約 20 秒後に「いまから、みつけるね」（字幕）。その 10 秒後から、座敷童子（身長 約 1.55m）が旅館中を走り回る
- 音は今はすべてオフ（`src/audio.js` の `SOUND_ON`）。セリフは字幕で出る
- 戸や障子窓が 1 つでも開いている部屋にいると、入ってきて襲われる。のれんの部屋（大浴場・洗面所・貸切風呂）は閉められないので危ない
- 全部閉めた部屋にいても、ときどき戸を叩いて「ここにいるの？」。5 秒後に戸を開けて中を探す
- 布団・押入れ・ロッカー・長持（蔵）に隠れていれば、ふつうは見つからない（ただし下の「音」と「記憶」に注意）
- 廊下で見つかると追いかけてくる。捕まると、一瞬まっ暗になってから目の前に「バァー」と飛び出してきて、六年二組の部屋で目をさます

### 座敷童子のかしこさ（`src/zashiki.js`）

- **音で寄ってくる**：走る（10m）・戸の開け閉め（8m）・隠れる（6.5m）・隠れ場所から出る（4m）・ふつうに歩く（3.5m）音が聞こえると、その場所へ見に来る（「……いま、音がした」）。閉まった部屋の中の音は壁ごしに 6 割しか届かない。別の階の音は聞こえない
  - **しゃがむ**（PC は C、スマホは「しゃがむ」ボタン）と足音はしない。戸の開け閉めは 4.5m、隠れるのは 3m に下がる。しゃがんでいると見える距離も 16m → 10m に縮む
  - スマホでスティックを少しだけ倒す「ゆっくり歩き」も、ほとんど音がしない
  - 画面下のまんなかの輪が、自分の立てた音の大きさ
- **隠れた音を聞かれると危ない**：隠れる音を聞いた部屋では、音のした近くの隠れ場所から順にのぞく。のぞかれた所にいると、低い確率で見つかる（「みぃつけた」）。見つかっても外に出されるだけで、約 1.3 秒だけ逃げる間がある
  - 「ここに、いるの？」とノックしている最中にあわてて隠れると、その音を聞かれる
- **記憶**：隠れたのを聞いた／目の前で隠れたのを見た／見つけた／のぞいて気配を感じた隠れ場所を約 3 分覚えている。覚えている所に続けて隠れると「また、ここ？」と開けられ、見つかりやすい。見つけた・追いかけた場所の近くにも、ときどき戻ってくる
- **見失ったら**：最後に見た位置と逃げた方向から、その先にありそうな部屋を近い順に 3 つ、ノックして探す（「どこ、かくれたの？」）
- **フェイント**：遠くからこちらを見つけると、立ち止まってじっと見つめてから走ってくることがある。何もないのに廊下でふと立ち止まり、こちらのほうを見ることもある。部屋を探して「いないね……」と立ち去ったふりをして、歌をやめて足音を消して戸の前に戻り、10 秒ほど待ち伏せすることもある（出てくると「やっぱり、いた」）
- **見つかる確率**（`findChance`）：何も手がかりがなければ 0（家具に隠れれば安全）。隠れる音を聞いた +22%、目の前で隠れた +40%、覚えている隠れ場所 +15〜30%、そこに続けて隠れた +10〜30%。最大 65%
- 動き（走る・ふらふら歩く・叫ぶ）は Higgsfield（Meshy）のリグで付けた（`assets/models/zashiki/`）

## 遊び方

```bash
npx http-server . -p 8123 -c-1
```

ブラウザで http://localhost:8123 を開く。

| キー | 操作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| マウス | 視点 |
| Shift | 走る（音が大きい） |
| C | しゃがむ／立つ（静かに動ける。しゃがんだまま隠れる・戸を開けると音が小さい） |
| E | 戸・障子を開ける・閉める、調べる（戸口を見れば、どちら側からでも） |
| E（布団・押入れ・ロッカー・長持の前） | 隠れる／出る |
| F | 懐中電灯 |
| M | 地図（いまの階の、行ったところだけ表示） |
| Esc | 一時停止（マウス感度・視野角・明るさ・上下反転の設定） |

### スマホ

横向きで遊ぶ。左手でスティック（画面の左側をさわったところに出る）を動かして移動、右手で画面をなでて見回す。右下の大きいボタンで戸を開ける・閉める・隠れる。スティックを少しだけ倒すと、そっと（静かに）歩ける。「走る」「しゃがむ」「灯り」「地図」ボタンと、左上の一時停止ボタンがある。

## 構成

- `src/plan.js` 間取り（3 階分の廊下・部屋・階段）
- `src/building.js` 間取りのマス目から床・天井・壁・戸・障子窓・階段・手すりを組み立てる
- `src/rooms.js` 部屋のなかみ（40 種類）
- `src/bath.js` 大浴場（脱衣所・富士山の壁画・ひのきの湯船・洗い場・湯気）
- `src/architecture.js` 障子・ふすま・格子戸・ガラス戸・のれん、柱／長押／欄間つきの壁、竿縁天井
- `src/models.js` 家具の 3D モデル（`assets/models/props/` の 30 個。Higgsfield で画像を作り、Tripo で 3D 化して圧縮）
- `src/props.js` `src/props2.js` 家具・小物（3D モデルがあればそれを使い、なければ箱で組んだ家具）
- `src/textures.js` 素材（`assets/textures/` の画像は Higgsfield で生成）
- `src/zashiki.js` 座敷童子（鬼）の動き（音を聞く・隠れ場所の記憶・見失ったあとの捜索・フェイント）
- `src/nav.js` 座敷童子の道さがし（マス目の経路探索、階段で階をまたぐ）
- `src/audio.js` わらべうた・足音・戸を叩く音・心臓の音・声
- `src/touch.js` スマホ用の操作（スティック・視点・ボタン）
- `src/main.js` 操作（階段の上り下り・小学生の目線）・設定・地図・灯り
- `assets/models/zashiki_warashi.glb` 座敷童子の 3D モデル（Higgsfield / Meshy で生成）
