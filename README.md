# 座敷童子（ホラーゲーム）

修学旅行で泊まった旅館が舞台の、一人称 3D ホラーゲーム。
旅館の間取りは毎回ランダムに生成され、一番奥の「奥の間」に座敷童子がいる。

## 遊び方

```bash
npx http-server . -p 8123 -c-1
```

ブラウザで http://localhost:8123 を開く。`?seed=数字` を付けると同じ旅館を再現できる。

| キー | 操作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| マウス | 視点 |
| Shift | 走る |
| E | 戸を開ける・調べる |
| F | 懐中電灯 |
| M | 地図 |
| R | 別の旅館を生成 |

## 構成

- `src/layout.js` 間取りの生成（7×7 のマスに 22 部屋、玄関から一番遠い部屋が奥の間）
- `src/rooms.js` 部屋の種類（21 種）
- `src/props.js` 家具・小物
- `src/world.js` 床・壁・引き戸・家具を組み立てる
- `src/main.js` プレイヤー操作・灯り・座敷童子の読み込み
- `assets/models/zashiki_warashi.glb` 座敷童子の 3D モデル（Higgsfield / Meshy で生成）
